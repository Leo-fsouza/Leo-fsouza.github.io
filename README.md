Sobre o projeto

Landing page pessoal criada para reunir, em um só lugar, minha apresentação profissional, experiências, projetos, tecnologias, formação e contatos. O site foi desenvolvido do zero, sem frameworks, com foco em um visual minimalista, boa leitura e funcionamento em qualquer tamanho de tela.

Funcionalidades
Tema escuro e claro: o tema escuro é o padrão, e o visitante pode alternar pelo botão no cabeçalho. A escolha fica salva no navegador.
Layout responsivo: a página se adapta a computadores, tablets e celulares.
Download do currículo: botão que baixa o currículo em PDF diretamente.
Navegação por seções: menu com rolagem suave até cada parte da página.
Cabeçalho fixo: o menu permanece visível durante a rolagem.
Acessibilidade: estrutura com tags semânticas, textos alternativos em imagens e rótulos descritivos nos botões.
Tecnologias
Tecnologia	Uso no projeto
HTML5	Estrutura da página com tags semânticas (header, main, section, article, footer)
CSS3	Estilização com variáveis para os temas, Flexbox, Grid e media queries para responsividade
JavaScript	Alternância de tema e armazenamento da preferência com localStorage
Google Fonts	Fontes Sora, IBM Plex Sans e IBM Plex Mono
GitHub Pages	Hospedagem e publicação do site

Como executar localmente
Clone o repositório:
bash
   git clone https://github.com/Leo-fsouza/Leo-fsouza.github.io.git
Acesse a pasta do projeto:
bash
   cd Leo-fsouza.github.io
Abra o arquivo index.html no navegador ou, no VS Code, use a extensão Live Server.

Não é necessário instalar dependências.
